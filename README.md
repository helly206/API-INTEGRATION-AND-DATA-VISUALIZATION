# Weather Dashboard App

***About the Project***
This is a simple weather dashboard built using Python and Streamlit. It shows the current weather of selected cities using data from the OpenWeather API. You can view temperature, humidity, wind speed, and weather description with a nice user interface and a bar graph.

***Tools and Libraries Used***
Python – Main language
Streamlit – To build the web app
Requests – To fetch data from the API
Plotly – To create a bar chart
OpenWeather API – To get real-time weather data
VS Code – Used as the code editor

***How It Works***
1. Select a city from the dropdown.
2. Click “Get Weather”.
3. The app shows weather details and a chart comparing temperatures.
How to Run

1. Install required libraries:
pip install streamlit requests pandas plotly

2. Run the app:
streamlit run weather_dashboard.py
